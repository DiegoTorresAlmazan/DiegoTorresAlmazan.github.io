Project

Customer Churn Prediction

An end-to-end machine learning project that predicts customer churn for a fictional B2B SaaS company, from data preprocessing to a REST API and an interactive dashboard.

Role
Full-stack developer
Stack
Python, SQL, scikit-learn, XGBoost, SMOTE, SHAP, FastAPI, Streamlit, Jupyter

Overview

This project predicts customer churn for "SynthSaaS", a fictional B2B SaaS company, and is structured to emulate a real-world production environment.

The business problem: SynthSaaS has a high churn rate, which hurts its Monthly Recurring Revenue (MRR) and long-term growth. The goal is a model that proactively identifies customers at high risk of churning, so the business can launch targeted retention campaigns (discounts, extra support, feature training) to reduce churn and increase Customer Lifetime Value (CLV).

What I did

I built the project as a series of modular, executable scripts and notebooks:

  • Exploration and interpretation: Jupyter notebooks for EDA, feature analysis, and model interpretation with SHAP.
  • Preprocessing: a script that loads the raw data, cleans it, engineers features and saves model-ready data.
  • Model training: handles class imbalance with SMOTE, trains Logistic Regression, Random Forest and XGBoost, evaluates them, and saves the best-performing model.
  • Prediction API: a FastAPI app that serves the trained model through a /predict endpoint returning real-time churn predictions.
  • Interactive dashboard: a Streamlit app for making predictions through the API and viewing key business insights from the model.

Along the way I:

  • Developed a full-stack analytics platform that automated churn prediction and dashboard generation, improving business reporting efficiency.
  • Built automated ETL validation workflows that cleaned, verified and transformed customer datasets before analysis, reducing manual data preparation.
  • Implemented REST APIs, validated application functionality, and ran end-to-end testing of the data processing workflows before deployment.

Outcome

A working churn-risk system: customers go in through the dashboard or API, and a prediction comes back that retention teams can act on.
