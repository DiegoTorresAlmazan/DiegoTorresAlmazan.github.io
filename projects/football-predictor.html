Project

Football Market Value Predictor

A machine learning model that predicts football player market value.

Role
Developer
Stack
Python 3.10, Pandas, Scikit-Learn, XGBoost, SHAP, FastAPI, Streamlit, Docker, Pytest, GitHub Actions

Overview

An end-to-end machine learning pipeline that predicts the market value of football players. It features a FastAPI backend, a Streamlit dashboard, and SHAP explainability to show why a player is valued at a certain price.

What I did

  • Interactive dashboard: a Streamlit interface to input stats and visualize results.
  • Explainable AI: SHAP values explain which stats (such as age or goals) drove the price up or down.
  • Production-ready API: a Dockerized FastAPI backend with input validation.
  • Automated tests: a full Pytest suite keeps the API stable, with GitHub Actions for CI.
  • Robust processing: handles missing values and categorical encoding (position, foot).

Outcome

A deployed, explainable model that anyone can try, backed by a tested, containerized API.
