Project

VR Rehabilitation App

A virtual reality application for physical therapy rehabilitation.

Role
Software Developer & Tester, CSUSM research project
Year
Aug 2025 — Dec 2025
Stack
Unity, C#, Meta Quest, Oculus SDK, Bertec force plates, Python

Overview

Built with Unity and the Oculus SDK, the app provides immersive exercises and real-time feedback to improve patient engagement and recovery outcomes.

What I did

  • Validated rehabilitation software across 28 participant evaluations by executing functional and integration test plans.
  • Identified synchronization defects and coordinated hardware and software verification between Meta Quest, Unity and Bertec force plate systems.
  • Developed Python automation scripts that transformed raw sensor logs into validated Excel reports, reducing researcher data preparation time and supporting repeatable verification.
  • Found and fixed data parsing, synchronization and stage detection defects through iterative functional and regression testing and documented verification procedures, in an Agile-style collaborative environment.

Outcome

More reliable rehabilitation software, validated across 28 participant evaluations, and a faster, repeatable data preparation workflow for researchers.
