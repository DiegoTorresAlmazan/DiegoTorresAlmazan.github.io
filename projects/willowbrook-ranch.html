Project

Willowbrook Ranch

A relaxing 3D farming game built with a team of five.

Role
Developer, team of 5
Year
CSUSM game development course
Stack
Unity 3D, C#

Overview

Willowbrook Ranch is a relaxing 3D farming game made with a team of five for my game development class at California State University, San Marcos. It was built in Unity 3D with animated characters, fishing mini games and interactable NPCs.

What I did

  • Implemented crop planting and harvesting.
  • Built the day-night cycle.
  • Worked with a team of five using Unity 3D and C#.
  • The game also includes animations, fishing mini games and interactable NPCs.

Outcome

A finished, playable game delivered as a team project for the course.
